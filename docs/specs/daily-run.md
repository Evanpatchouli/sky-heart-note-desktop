# 代跑服务与验收样单

本轮按委托使用模拟样单确定代跑规则。服务为老板委托执行人按约定路线完成每日跑图。订单记录老板游戏号、服务约定、首个北京业务日和连续服务天数。样单中的账号、交付凭据和转账编号均为示例。

## 办理与计价

- 老板在客户端下单，或由团员代已注册的老板录单。客户端订单保留派单归属，代录订单由录入团员经办。订单归属本人后，派单人核实足额线下首款并主动派发。一个有效团员承接整笔订单。
- 每个约定日是一个独立验收单位。执行人按日期填报完成情况及交付凭据，可使用任务清单或截图的引用。老板逐日确认。相同业务日的重复提交只形成一份有效交付。派单人能核对进度，财务按授权核对款项。
- 本轮商定每个验收日服务费 20.00 元，其中派单人 2.00 元、团费 1.00 元、执行人 17.00 元。建单时保存当单约定，以整数分核算。全部日单位均经老板确认后完成履约。
- 老板可带原因取消后续服务。停单保留原始交付、凭据和已确认日期。已收费的未验收日每个应退 20.00 元，实际退款另登记。尚未收款的取消单无现金退款。派单人核对客户净实收等于已验收日的分配合计后确认结单，个人余额与团费从此时入账。

## 普通单 R1

老板在客户端给游戏号「晨云」订购 11 月 20 日至 22 日的三日跑图。派单人核实首款 60.00 元并发布。一名团员承接，分别提交 `R1-20`、`R1-21`、`R1-22` 三份路线完成凭据，老板逐日验收。财务可从订单查到首款、三份凭据及结单分录。

## 取消单 R2

团员为游戏号「暮云」代录相同约定，核实首款 60.00 元。执行人提交首日凭据 `R2-20`，老板确认后因行程变化取消余下两日。应退 40.00 元。模拟先退 15.00 元，再退 25.00 元，首笔登记后尚待退 25.00 元。退足后的净实收为 20.00 元。

## 三端办理入口

客户从「下单」或「我的订单」选择代跑，团员从「派单」「接单」或「我的承接」进入本业务，管理端从「订单监管」查看。订单列表可按业务类型翻页。代跑单与送心单分别保存交付依据。

| 请求 | 用途 |
| --- | --- |
| `GET /api/{app}/club/service-orders`、`GET /api/{app}/club/service-orders/:id` | `app` 为当前登录端。代跑使用 `businessType=daily_run`。团员的 `scope=dispatch`、`board`、`mine` 对应经办订单、接单区及本人承接。 |
| `POST /api/{client或employee}/club/service-orders` | 填写游戏号、路线约定、首个业务日及天数。团员代录时指定已注册客户的四位 ID。 |
| `POST …/:id/assign`、`POST …/:id/publish` | 团长或副团长安排待分配单。经办团员核对首款金额（分）及实际收款时间后派发。 |
| `POST …/:id/claim`、`POST …/:id/deliveries` | 有效团员领取整单，执行人按从 1 开始的日序号 `unit` 提交 `evidence`。 |
| `POST …/:id/accept`、`POST …/:id/stop` | 老板确认相应日的交付。停单提交 `reason`，保留已确认日期及凭据。 |

写入携带 UUID v4 的 `requestId`，同一次操作重试沿用原标识。服务端依据当前会话校验归属及动作，客户仅能读取本人订单。运营人员与财务的可见金额按授权返回。
