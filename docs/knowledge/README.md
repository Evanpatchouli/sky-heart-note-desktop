# 工程知识

- 赠送次数、预计实收颗数和实际到账颗数分别记录。排查金额时先确认计价口径，再核对订单计价段和结单流水。[数量与金额口径](../heart-delivery.md#数量与金额的口径) · [按次结算](../club-orders.md#按次结算)
- 四位用户 ID 是字符串，需保留前导零。旧 SQLite 文件按 ID 归属，导入使用事务。重复导入相同内容会跳过，遇到相同 ID 或键但内容不同会整体回滚。[旧库导入](../../README.md#团员数据与旧库导入)
- 登录问题先核对请求的 `app`、Origin 和会话。平台角色控制应用准入，俱乐部成员资格和订单职责控制具体业务动作。[准入实现](../../server/src/auth/app-access.ts) · [职责矩阵](../club-business.md#对象级职责矩阵)
- 已安装的 PWA 更新后需关闭该端全部窗口和标签页，再从图标打开。[真机验证](../runbooks/testing.md#真机验证)
